## 🚀 Things I've Built

### 📱 [PayPath: Salary Calculator](https://play.google.com/store/apps/details?id=com.paypath.app) — *live on Google Play*
A Flutter app for tracking work hours and pay. I built it for myself while working an hourly job, because the alternatives were full of ads and paywalled basic features like export. It's now public, localized, and still growing.
`Flutter` `Dart`

### 🏋️ GymBud *(in progress)*
A gym-buddy matching mobile app: discovery, onboarding, workout sessions, GPS + QR check-in, group workouts and a trainer storefront with verified reviews.
`Flutter` `Express` `TypeScript` `MongoDB`

### 🧸 Kindergarten Management App
Cross-platform kindergarten management app, built as my Master's thesis.
